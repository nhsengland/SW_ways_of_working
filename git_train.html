Learning Hub

Learn the basics of version control with Git, the world’s most popular version control system. This course covers source control, distributed version control systems, and hands-on Git commands

https://learninghub.nhs.uk/resource/63354

Seting up Git and GitHub

Set up GitHub and GitHub Desktop

https://prototype-kit.service-manual.nhs.uk/guides/github/setup-github-desktop/

Introduction to Git and GitHub (RStudio)

An introduction to Git and using GitHub using RStudio as an IDE (integrated development environment) using the built in tools within RStudio and also with the packages {gert} and {usethis}

https://www.strategyunitwm.nhs.uk/introduction-git-and-github-rstudio

Accredited training by microsoft is accessible via your nhs.net email account.

The courses can be found here https://learn.microsoft.com/en-us/training/github/
